# Análise Exploratória de Mortalidade Infantil no Brasil

## Objetivo
Investigar como a mortalidade infantil variou por região brasileira entre 2010 e 2023,
identificando padrões, desigualdades e tendências ao longo do tempo.

## Perguntas investigadas
- Qual região tem maior taxa de mortalidade infantil?
- O Brasil melhorou ao longo dos anos?
- Como cada região evoluiu no período?

## Principais insights
- Nordeste e Norte concentram as maiores taxas do período
- Houve queda consistente nacional entre 2010 e 2023
- Desigualdade regional persiste — Nordeste com taxa quase 2x maior que o Sul

## Ferramentas utilizadas
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## Como executar
1. Clone o repositório
2. Instale as dependências: `pip install pandas matplotlib seaborn`
3. Abra o arquivo `notebook/analise_mortalidade_infantil.ipynb`
4. Execute todos os blocos em ordem
